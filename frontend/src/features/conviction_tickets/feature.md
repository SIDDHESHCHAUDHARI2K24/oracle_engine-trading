# Conviction Tickets

## Overview
ML-generated trading conviction tickets with backtest validation. Tickets are generated by the pipeline engine and presented to users for review and action.

## API
- `GET /api/v1/tickets` - List with filters (universe, horizon, conviction, passes)
- `GET /api/v1/tickets/{id}` - Single ticket detail
- `GET /api/v1/tickets/history` - Historical tickets with outcomes
- `POST /api/v1/tickets/{id}/review` - Mark ticket as reviewed
- `POST /api/v1/tickets/{id}/action` - Mark ticket as actioned with notes

## Routes
- `/tickets` - Inbox (filterable, sortable table)
- `/tickets/:id` - Ticket detail with actions and backtest link
- `/tickets/history` - History with status/outcome filters

## Components
- `ConvictionBadge` - Color-coded conviction score badge
- `ConformalIntervalBar` - Visual bar showing prediction range
- `BacktestPassTable` - 4-strategy pass/fail summary table

## State
- TanStack Query with 60s polling on inbox
- Optimistic updates on action mutation
- Key factory: `ticketKeys`
